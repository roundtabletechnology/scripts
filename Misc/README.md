# Misc

Standalone utilities that don't belong to a specific platform or product category.

See [HOWTO.md](../HOWTO.md) for guidance on downloading and running scripts.

---

## Scripts

| Script | Description |
|---|---|
| [Audit Password Strength.py](Audit%20Password%20Strength.py) | Offline password strength and compliance audit. Takes a hidden prompt, a plain list or a CSV column, and reports PASS/FAIL against NIST SP 800-63B-4, CIS, PCI DSS 4.0.1 and OWASP ASVS 5.0, plus legacy Windows complexity. Optional offline wordlists and an offline HIBP Pwned Passwords copy. Python 3 standard library only. |
| [Generate Huntress Site Key.py](Generate%20Huntress%20Site%20Key.py) | Generates a Huntress organization site key via the Huntress API. Requires an API key and account credentials. |
